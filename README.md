# JDLite

⚠️**Disclaimer**⚠️

JDLite was developed entirely using AI.

As a result, bugs, unexpected behaviour, and other issues may occur. Features may not always work as intended, and users should exercise discretion when using the application.



A lightweight iOS download manager inspired by jDownloader 2.

JDLite aims to provide a clean, streamlined experience for managing downloads on iOS.

## Features
* TorBox Integration — Exclusively uses TorBox to manage downloads.
* iOS Focused — Designed specifically for the iOS experience.
* Simple & Streamlined — Inspired by jDownloader, with an emphasis on ease of use.

## Compatibility
Currently, JDLite exclusively supports TorBox. Support for other debrid services have not been added due to TorBox being the only debrid service currently available to me for development and testing.
